# Rerendering

Proves that **frequent React re-renders** inside `TransformComponent` do not
disrupt the current zoom or pan state. Three regions update on independent
timers (1 s, 3 s, 12 s). Each toggle is not a text swap — it **restructures the
layout**: compact card vs three-column grid, sidebar split vs hero + stats +
two-column dashboard, minimal strip vs tall stack with gallery, list rows, and
footer. Total content height changes a lot between states.

Every reflow is animated (the blocks transition their height), so the content
keeps changing size for a few hundred milliseconds at a time. The library
re-checks the bounds on every size change: when a block collapses under a view
that sits at the bottom edge, the content follows the reflow and settles with
the usual alignment animation instead of leaving a gap — and it never moves
while the view is already inside the bounds.

Scroll the trackpad to pan and hold <kbd>Ctrl</kbd>/<kbd>⌘</kbd> while scrolling
to zoom (`wheel.activationKeys` + `trackPadPanning`). Watch the layout reflow
without resetting your viewport. This matters for dashboards, live data, and any
UI where structure and size change under the user’s feet.
