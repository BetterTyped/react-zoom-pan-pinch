# Padding

The **padding** is the area past the content boundaries that the content can be
pulled into. By default (`disablePadding: false`) dragging past an edge
stretches like a rubber band, the curve iOS scroll views use: the content
follows at about half the pointer's speed, resists more the further it is
pulled, and springs back on release. `autoAlignment.sizeX` / `sizeY` set how far
it can go (100 px by default). The band only approaches that distance, so a
larger value gives a longer stretch that is easier to feel. The rubber band
needs `autoAlignment` enabled; with it disabled the content follows the pointer
1:1 up to the padding edge and stays there.

When `disablePadding` is set to `true`, panning and zooming are strictly
clamped: the content stops exactly at its edges.

Use the **Stretch** chips to compare padding sizes and the **toggle button** in
the control bar to switch padding off. The status badge shows the current mode.
